# Student Record Management System 🎓

A desktop-based Student Record Management System built using **Java (Swing)** and **Object-Oriented Programming (OOP)** principles. This application implements role-based access control, allowing secure portals for both Students and Administrators.

## 🚀 Features

### 👤 Student Portal
* Secure login using Student ID and password.
* Read-only access to personal details (Name, Age, Mobile Number, CGPA, Attendance, and Course History).

### 🛠️ Admin Portal
* Secure administrative login.
* Full control to add new students, update existing records, and remove student profiles.
* View and manage the complete database of student records.

---

## 🛠️ Tech Stack
* **Language:** Java
* **GUI Framework:** Java Swing, AWT, CardLayout
* **Architecture:** Object-Oriented Programming (OOP) principles with decoupled model and database layers.
